Same white-card layout as today, tightened: bigger prices, readable label chips (no 9px text), a “Sizes” list, and Regular pre-selected as the default size.

Card anatomy (matches your reference)

  • Landscape card, roughly 3 : 2, radius 28px.
  • Image fills the whole card — object-fit: cover, never stretched.
  • Category pill top-left (from the item's existing category).
  • Name (largest, up to 2 lines) → sizes → price, stacked bottom-left.
  • Dark scrim over the lower part keeps the text readable on any photo.
  • In-cart count pill top-right; no image → branded fallback tile.
  • No + button anywhere — the card is the tap target.

Behaviour & information

  • The base (“Regular”) price is always shown, followed by each size and its own price — so a priced item never loses its price when it has sizes.
  • Every option stays tappable (underlines on hover): “Regular …” adds the item as-is, each size adds that size — size selection is never lost.
  • No sizes → just the single price.
  • A sold-out item shows Sold out instead of the price and is disabled.
  • Shown: name, category, price(s), sizes, sold-out, in-cart count.
  • Not shown: SKU, barcode, cost price, tax category, stock mode, labels, description — SKU/barcode still work through search, category through the rail.
  • Click the card to add — exactly once.
